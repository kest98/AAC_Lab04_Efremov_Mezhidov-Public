Контрольные вопросы

1. Что показывает Environment.ProcessorCount?
Показывает сколько логических процессоров.
2. Чем физическое ядро отличается от логического процессора?
Физическое ядро - это часть процессора, а логический процессор это то как выглядит ядро для системы
3. Почему увеличение количества потоков может увеличить загрузкуCPU?
Когда потоков больше, программа может свою работу разделить на несколько логических процессоров одновременно. И поэтому общая нагрузка растет
4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти?
Потому что все логические процессоры уже заняты. 
5. Почему частота процессора может изменяться во время работы?
Процессор сам меняет частоту в зависимости от ситуации.
